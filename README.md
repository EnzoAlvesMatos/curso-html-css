# Projeto de HTML e CSS

<h2>🖱️ Sobre o Projeto</h2>
<p>Eu criei este projeto com o objetivo de treinar e aprender a utilizar HTML e CSS, além de conhecer melhor
  essas ferramentas. O projeto é dividido em atividades e desafios, que desenvolvi conforme avanço no curso de HTML e CSS.</p>

<h2>🧠 O que estou aprendendo</h2>
<p>Neste projeto, aprendi a utilizar o HTML de forma semântica e conheci diversas tags. Também aprendi a
  adicionar vídeos, imagens e sons aos meus sites. Em CSS, aprendi bastante sobre teoria das cores, como utilizar
  fontes corretamente, entre outras coisas. Ainda estou aprendendo e aprimorando meus conhecimentos.</p>
